# Third-party components

Будка использует сторонние библиотеки и ресурсы. Их лицензии действуют отдельно.

| Компонент | Лицензия | Файл |
| --- | --- | --- |
| Godot Engine | MIT | https://godotengine.org/license |
| GodotSteam | MIT | `addons/godotsteam/license.md` |
| Con  | MIT | `addons/conn/LICENSE` |
| L | MIT | `addons/l/LICENSE` |
| TwoVoIP | MIT | `addons/twovoip/LICENSE` |
| libopus | BSD-3-Clause | `addons/twovoip/LICENSE.opus` |
| RNNoise | BSD-3-Clause | `addons/twovoip/LICENSE.rnnoise` |
| SpeexDSP | BSD-3-Clause | `addons/twovoip/LICENSE.speexdsp` |
| gd_desktop_caster | MIT | `addons/gd_desktop_caster/LICENSE.txt` |
| Adwaita icons | LGPL-3.0 или CC BY-SA 3.0 | `assets/icons/README.md` |
| Adwaita Sans | SIL Open Font License 1.1 | upstream `adwaita-fonts` |
| Логотип Budka | ресурсы Flaticon.com, требуется атрибуция | https://www.flaticon.com/ |

`ffmpeg` не входит в поставку и устанавливается отдельно; его лицензия зависит от сборки (LGPL/GPL).
