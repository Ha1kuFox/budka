# Icons

All SVGs are symbolic icons from `adwaita-icon-theme` 50.0
(`symbolic/actions`, `symbolic/status`, `symbolic/categories`). The original
`fill="#2e3436"` was replaced with `#ffffff` so they read on the dark theme.

| File | Adwaita name |
| --- | --- |
| `exit.svg` | `system-log-out-symbolic` |
| `mic.svg` | `microphone-sensitivity-high-symbolic` |
| `sound_full.svg` | `audio-volume-high-symbolic` |
| `broadcast.svg` | `screen-shared-symbolic` |
| `settings.svg` | `preferences-system-symbolic` |
| `fullscreen.svg` | `view-fullscreen-symbolic` |
