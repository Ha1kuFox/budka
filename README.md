# Будка

**Будка** — тестовый некоммерческий войсчат для компании друзей: голос через Steam, список участников и трансляция экрана без отдельного сервера.

> Проект создан для теста. Коммерческое использование запрещено. См.
> [LICENSE](LICENSE) и [THIRD_PARTY_LICENSES.md](THIRD_PARTY_LICENSES.md).

## Возможности

- Голосовой чат в комнате через Steam Networking (Opus, RNNoise, AGC).
- Список участников с превью их трансляций и индикатором речи.
- Трансляция экрана: H.264, 1280×720, 24 fps, ~1.5 Мбит/с, GOP 1 с.
- Локальный превью хоста, удалённые превью декодируются отдельно для каждого участника.

## Требования для запуска

- Steam-клиент и собственный Steam App ID (в проекте пока стоит тестовый `480`).
- **ffmpeg** с `libx264` и H.264-декодером в `PATH`.
- Linux: PipeWire + XDG Desktop Portal для захвата экрана.
- NixOS: `steam-run` для запуска обычного Linux-бинарника в FHS-окружении.
- Windows: Visual C++ Runtime (обычно уже есть в Steam).
